# 任务 02：便利店可玩化（人物移动 / 自动门 / 进店 / 跟随镜头）

分支：`feature/store-walk-in`　备份标签：`backup/orbit-diorama`

## 目标

原场景是一个只能看的微缩模型：轨道相机在天上转，人物是开场动画的道具，
便利店只有橱窗（门是画在玻璃上的两片板，店内进不去）。这一期把它变成
「人站在街角，能推门走进店里」的可玩场景，同时不破坏原来的展示版。

## 做了什么

### 1. 先备份，再动刀

| 层级 | 内容 |
| --- | --- |
| 标签 | `backup/orbit-diorama`，指向改造前提交，可整棵还原 |
| 可运行副本 | `scenes/diorama_orbit.tscn` + `scripts/backup/diorama_orbit.gd`（`main.gd` 逐字副本） |

副本冻结的是**编排**（机位 / 灯光 / 开场 / 角色站位），几何库仍指向当前版本。
要逐字节复现，checkout 标签。

### 2. 让店「能进去」

原布局不是给走路设计的：

- 踢脚墙（0.55m 高）横跨整个立面，包括门洞 —— 视觉上是一道门槛墙；
- 三排货架间距 1.05m，架深 0.52m，净过道只有 **0.53m**，胶囊直径 0.64m 过不去；
- 收银台堵在门口右侧。

`Store.build()` 增加 `walkable` 选项（默认关闭，展示版完全不变）：

- 踢脚墙与压条按门洞（x −0.33..1.04）断成两段；
- 两块横向货架（x −0.95..0.95，净过道 0.83m），东侧留 1.2m 主通道；
- 收银台沿东墙布置（旋转 −90°），台面抵住内墙，过道 1.2m；
- 冷柜前留 0.85m 站立区，东墙补两排壁架填住空出来的墙。

`Store.layout(walkable)` 成为**视觉与碰撞的唯一真源**：
`_interior()` 和 `collision_layout.gd` 都读它，避免「看得见走不过去」。

### 3. 碰撞与高差

整个场景原本零碰撞体。新增 `scripts/collision_layout.gd`：只挡大体块
（地面 / 墙 / 货架 / 台面 / 杆件 / 底座边界），小摆件该穿就穿。

两处必须走上去的高差用**隐形楔形**（`ConvexPolygonShape3D`）补，而不是给
`CharacterBody3D` 加自动上台阶 —— 那套逻辑一改，草原场景的手感会跟着变：

- 店门槛：人行道 0.16 → 店内 0.25，9cm；
- 路缘：马路 0.0 → 人行道 0.16，16cm，两条临路的边各一条 25cm 宽斜面。

### 4. 自动门

`scripts/autodoor.gd`：两扇门叶各自是一个 `AnimatableBody3D`，
玻璃 / 门框 / 把手 / 碰撞盒都是它的子节点，开合补间挪的是物理体本身 ——
「门开了」和「人能过」是同一件事，不会出现门开了但被隐形墙挡住。

- 感应 2.35m 开、离开 0.45s 关；人卡在门洞里不关；
- 门楣感应灯：关=红、开=绿（`kit.glow` 缓存材质切换）；
- 开关门播两音「叮—咚」（运行时合成 PCM，`scripts/sfx.gd`）。

### 5. 跟随镜头

复用了草原的 `player_controller.gd`，补了三件事：

1. `actor_tint / shade_floor / rim_strength / outline_width` 提成导出参数
   （草原是白天，雨夜要压暗偏冷；默认值保持草原原样）；
2. `set_camera_profile()` / `snap_camera()`：距离 / 支点高度 / FOV / 肩部偏移
   平滑过渡；肩部偏移用 `Camera3D.h_offset`，不影响弹簧臂的碰撞射线；
3. 状态：街道 3.9m / FOV 52°；店内 1.6m / FOV 70° / 右肩 0.28。
   店面只有 4.2×4.2m，臂长再长一点镜头就永远贴在货架或柜台边上。

另外加了一张**接触阴影**：夜景主光只有 0.55 能量，脚底几乎没有影子，
近看像贴纸。脚下挂一张 Alpha 径向渐变面片，每帧向下打射线贴地，
跳起来缩小变淡。

### 6. 交互与反馈

- `interaction_hub.gd`：每帧算水平距离，最近的交互点参与提示，按 `E` / `F` 触发。
  没用 Area3D —— 目标少且静止，省一层碰撞层配置。
- 交互点：冷柜（拿罐装咖啡）、货架（随机三条文案）、服务铃（合成铃声）、门口的猫。
- `hud.gd`：标题卡 / 区域指示（店内·HOSHI MART）/ 底部交互提示 / 物件反馈 / 操作说明。
- 进店时曝光 1.12 → 0.92（店内三盏暖光正对天花板，不压会烧白），
  雨声 −15 → −26dB、店内低频 −40 → −24dB。

### 7. 开场

不再是黑场切场景：从原微缩场景同机位（yaw 26° / pitch 14.5° / dist 17）
用 3.6 秒推镜到人物背后，再用跟随相机接管。第一帧和 `shots/a_front.png` 对齐。

## 自测

```bash
./Godot_v4.7.2-stable_linux.x86_64 --headless --path . res://tools/walk_probe.tscn
```

9 条断言：自动门感应、跨过门槛、踩上 0.25m 地板、走到冷柜前、提示文案、
离开后关门、退回室外、爬上 16cm 路缘。当前全绿。

```bash
./Godot_v4.7.2-stable_linux.x86_64 --path . -- --shot
```

输出 5 张：`walk_a_overview` / `walk_b_street` / `walk_c_door` /
`walk_d_inside` / `walk_e_aisle`。

## 已知限制

- 人物动作仍是程序化摆骨骼（模型无动画剪辑），走跑只有摆臂摆腿，没有转身过渡；
- 店内只有 4.2 × 4.2m，第三人称在门附近时镜头会被门框收得很短（弹簧臂正常行为）；
- 门只有前门可开，后门 / 后巷仍是布景；
- 收银台没有店员，按铃只有声音和一句文案 —— 这是刻意的（雨夜、无人店）。
