# 雨声环境音规格

> 对象：`audio/street_rain_loop.wav`（商店街）、`audio/gas_station_rain_loop.wav`（国道加油站）
> 生成：2026-10-27，第 4 版。纯电子合成，无采样。全部数值为**实测**，测量方法见文末。
> 用途：两个场景的 `&"rain"` 命名声道（见 [`音频总线.md`](音频总线.md)）。

第 4 版改的是**雨滴的时间结构与音色**。第 3 版的频谱、响度、循环都在目标内，但试听反馈是「雨滴像电流声」。
电流声的物理本质是规则的窄带高频脉冲串：第 3 版 213.9 / 223.8 滴每秒（平均间隔 4.5ms）、每滴一段 Q2–5 的高频音爆发、
再叠一个 2 样本 click，正好是「200 Hz 以上的重复率 + 窄带 + 尖锐边沿」的配方。第 4 版把雨滴改成**成簇到达 + 宽带拍打**：

| 听感 | 诊断 | 第 4 版的做法 | 实测结果 |
| --- | --- | --- | --- |
| 电流滋滋 | 213/s 均匀泊松 + 窄带音爆发 + click | 成簇到达；单滴改成带通噪声 | 间隔 CV **1.01 → 1.91 / 1.89**；雨滴分轨 150–350Hz 调制深度 **121.7% → 32.7 / 32.2%**，200–500Hz **100.7% → 24.9 / 24.6%**（v3 基线为街） |
| 单滴像音高 | Q2–5 谐振器、共振 2–6kHz、1–5ms | Q2–4 带通噪声、1–3kHz、0.4–1ms attack + 3–7ms 指数衰减、无 click | 雨滴分轨 4k / 8k 从 **+11.6 / +4.1** 降到 4k **−5.5 / −6.1**、8k **−14.9 / −15.3**（相对 1k） |
| 高频裸露 | 共振落在雨幕的滚降区，没有掩蔽 | 共振下移到雨幕 2kHz 峰的下面 | 2k 带能量雨滴比雨幕低 **10.6dB**、4k 低 **12.4dB**；整轨 2k 仍是 **+3.2 / +3.1dB** |
| 密度的中间态 | 213/s 均匀撒点，既不可数也不连续 | 不平移密度；3–8 滴/簇、簇间 20–80ms、簇内 1–3ms | **133.0 / 141.0/s = 23.1 / 24.1 簇/s × 5.8 / 5.9 滴**；83% 间隔 <8ms；簇间 33.6 / 31.5ms |
| 限幅 / 量化 | 前视限幅可能逐颗压瞬态 | 限幅保持 −1.5dBFS / 2ms / 180ms；事件尾部 0.5ms 淡出 | 最大衰减 **0.00dB**；真峰 −9.5 / −9.4，离阈值 8dB |

## 一、声学 / 物理属性

### 三层结构

| 层 | 频段 | 做法 | 层电平（相对雨幕 RMS） | 空间处理 |
| --- | --- | --- | --- | --- |
| ① 风涌 `wind` | 20–300 Hz | 噪声 → **时变低通**（截止由随机游走驱动，70–300 Hz）→ 20 Hz 高通 → 1 阶 420 Hz 低通；振幅由另一条独立随机游走驱动，**±6 dB**（0.5s 栅格，约 20s 平滑） | **−3 dB** | 干声，不送混响 |
| ② 雨幕 `rain` | 主雨沙 250 Hz–5.2 kHz，8 kHz 以上滚降 | 噪声 → 250 Hz 1 阶高通 → 320 Hz/Q1.3 **+1.2 dB** → 650 Hz/Q1.0 **−1.5 dB** → 2 kHz/Q1.0 **+2.5 dB** → 4 kHz/Q0.9 **−4.0 dB** → 4 阶 5.2 kHz 低通 → 7 kHz/Q0.7 **−3.0 dB**；另叠 180–700 Hz「地表体感」（320 Hz +1.0 dB，BODY 0.75）；**慢包络 −4.5…+4.5 dB**（20–60s）+ **8–30 Hz ±0.9 dB** 微纹理；**没有 0.5–5 Hz 调幅** | **0 dB（基准）** | 送混响 |
| ③ 雨滴 `drops` | 带通 1–3 kHz | 每滴 10.9–25.5 ms：白噪 × **0.4–1 ms 升余弦 attack** → **1–3 kHz 带通（Q 2–4）** → **3–7 ms 指数衰减** + 0.5 ms 尾部淡出；**没有 click**。成簇到达：3–8 滴/簇、簇内 1–3 ms、簇间 20–80 ms；幅度 Pareto（**α=1.7**）重尾，上限 median×10；均值 **133 / 141/s** | **−12.0 dB** | 送混响 |

- **三层各有独立包络**：风涌的截止与振幅、雨幕的慢包络与微纹理、雨滴的簇密度与逐滴随机都没有共用控制源。它们不会「一起呼吸」。
- **风涌的「非周期」来自随机游走**：截止和振幅是两条独立的环形随机游走，不是正弦 LFO。变亮和变响可以错开，听感上没有固定周期。
- **雨滴是成簇的，不是均匀脉冲串**：133.0 / 141.0 滴每秒，但只分成 23.1 / 24.1 簇每秒；每簇 5.8 / 5.9 滴，簇内间隔 1–3ms，簇间 33.6 / 31.5ms（gamma(3)，CV 0.57 / 0.58）。全段间隔 CV **1.91 / 1.89**，83% 的间隔 <8ms，p99 70.2 / 68.0ms——短间隔成串、长间隔留白，这是「一阵一阵的雨」而不是「持续的脉冲」。
- **为什么簇化能消掉电流感**：均匀泊松的雨滴在包络上几乎是一条等幅脉冲串，第 3 版雨滴分轨在 150–350Hz 的调制深度是 **121.7%**、200–500Hz 是 **100.7%**，人耳把这个重复率读成「滋滋」。成簇之后，高重复率的能量被限制在每簇 10–20ms 的短爆发里，整段包络的主调制落到 **20–50Hz**（101.8%），150–350Hz 掉到 **32.7%**、200–500Hz 掉到 **24.9%**。平均密度只降了 38%，听感却从「电流」变回「雨」。
- **密度没有走「<80 或 >400」的两端**：均匀分布时 213/s 确实是最危险的中间态；但成簇以后，局部密度在每簇内是 330–1000/s（1–3ms 间隔），簇间是 0，时间结构不再均匀。平均 133 / 141/s 只是簇率 × 每簇滴数的结果，不是「均匀 133/s」。
- **单滴是宽带拍打，不是音高**：带通噪声的带宽是 fc/Q = 250–1500Hz，Q 2–4，共振上限 3kHz；0.4–1ms 的升余弦 attack 把边沿的宽带「咔」也去掉了。雨滴分轨的 1/3 倍频程在 1.6–2.5kHz 是一个 +2~3dB 的宽平台，3.15k 已经落到 −1.1dB，4k / 8k 是 −5.5 / −14.9dB（相对 1k）——第 3 版对应的值是 +10.8 / +11.9（2.5k / 3.15k）、+11.6 / +4.1（4k / 8k，均为街）。
- **雨滴被雨幕掩蔽**：带能量上，雨滴层在 2k 比雨幕低 **10.6dB**、4k 低 **12.4dB**、8k 低 **10.0dB**；重尾大滴的峰值仍能高出雨幕，但绝大多数雨滴不再「孤零零地露在高频」。因此本轮**没有**再抬雨幕 2–4kHz——掩蔽由「雨滴下移」完成，整轨的 2k 仍是 +3.2 / +3.1dB，没有改动第 3 版已经验收的频谱。
- **没有第四层**：没有雷、没有金属击打、没有车流、没有音乐。情绪靠三层各自的缓慢运动，不靠事件。

- **读表前先看这个**：倍频程表是**每倍频程的总能量**，不是中心频率的功率密度。白噪声在这种表上天然是 **+3 dB/倍频程**（每个频带越来越宽），所以「8k 比 1k 低 8.8 dB」不等于「8k 的密度只低 8.8 dB」。同一份文件按 1/3 倍频程**点密度**看，8k 比 1k 低 **19.4 / 19.1 dB**，16k 低 **30.3 / 30.4 dB**——高频被削得比带能量表看起来更狠。
- **8 kHz 以上被压下去了**：带能量 8k 比 1k 低 8.8 dB，16k 低 19.1 dB；点密度 8k 低 19.4 / 19.1 dB。第 4 版比第 3 版在 8k 又暗了 1.5 dB、16k 又暗了 2.4 dB（带能量），主要因为雨滴不再往 4k 以上投窄带能量；高频只负责空气感，不负责主体。
- **4 kHz 不抬**：带能量 +0.5 dB（频带变宽的 +3 dB/oct 补偿之内），点密度比 1k **低 3.9 / 4.4 dB**。4 kHz 上那个 −4 dB 的宽峰把「沙」压掉了。
- **1–3 kHz 是雨幕能量峰**：2k 带能量比 1k 高 3.2 / 3.1 dB，点密度 +2.8 / +2.6 dB；2k 比 8k 的带能量高 12.0 dB。雨沙的主体落在人耳最敏感、但不刺耳的区间。
- **中频包在 250–320**：1/3 倍频程 250 / 315 / 400 是 **+4.1 / +3.7 / +1.0**（街）、**+4.6 / +3.0 / 0.0**（站）。250 比「+2~3」的目标高一点，但它与 20–300 Hz 的风涌托底连成一片，是宽而浅的低中频体感，不是独立的「嗡嗡」腔体。
- **500–800 Hz 是平的**：1/3 倍频程 500 / 630 / 800 为 +0.7 / +0.6 / −1.1（街）、+0.3 / +0.7 / +0.4（站）。交叉区既没有坑，也没有包。
- **无共振峰**：40 Hz–16 kHz 内没有任何窄峰高出 ±1/3 倍频程中位数 6 dB（自动检测，见文末）。雨滴是带通噪声拍打，不是阻尼正弦，Q 上限只有 4，不构成驻波或音高。
- **63–250 Hz 仍有托底**：带能量只比 1k 低 1–3 dB，给「空气在动」的体积感；500 Hz 以上让位给雨幕。

- **峰值因数变低了，不是变平了**：第 3 版的峰值因数是 20.9 / 20.6 dB，第 4 版是 17.3 / 17.7 dB——差的 3dB 正好是「2 样本 click + 高 Q 音爆发」那部分尖峰。重尾雨滴仍在，最大的单滴比整轨 RMS 高约 17dB，只是不再是 1–5ms 的针尖。
- **缓慢起伏，仍然不是平线**：逐秒 RMS 的 p10–p90 是 **8.18 dB（街）/ 8.65 dB（站）**，全段极差 8.9 / 9.9 dB。LRA 8.3 / 8.6 LU，落在 6–9 的目标区间。
- **两个慢包络负责段落感**：雨幕有一条 **±4.5 dB、20–60s** 的宏观包络，雨滴事件也乘同一条包络（大雨势段雨滴更响）；风涌另有一条 ±6 dB、约 20s 的独立振幅游走。三条曲线不同源，所以不会整条曲子一起呼吸。
- **峰值来自重尾雨滴，不来自事件**：全曲最响的 5 秒是 60 / 67 / 63 / 48 / 57 s（街，−9.7 ~ −10.4 dBFS）和 74 / 70 / 69 / 71 / 83 s（站，−9.4 ~ −10.0 dBFS）——都是大滴叠在大雨势段上的瞬间，没有雷那种孤立高峰。
- **限幅器实际上没工作**：16-bit 母版在静态增益后过一台**环形前视限幅器**（阈值 −1.5 dBFS、前视 2 ms、恢复 180 ms）。实测最大衰减 **0.00 dB**、触发 **0.000%** 的样本——输入真峰只有 −9.5 / −9.4 dBFS，离阈值还有 **8.0 / 7.9 dB**。它现在只是保险丝。
- **为什么仍出 −23 LUFS**：场景侧 `db` 按 −23 LUFS 素材标定（−12.5 dB → 有效 −35.5 LUFS），提高素材响度会让雨在三个场景里同时变大声，得连带重调 `hoshi_street` / `gas_station` 的音量档。本轮的目标是音色与微观结构，不是响度；要更响，改场景的 `db` 一档即可，别重新削素材。

### 信噪比与纯净度

- **没有录音底噪**：不存在话筒自噪、电流声、空调嗡鸣。基底全部来自合成噪声，安静段也是「雨的安静」而不是「设备的安静」。
- **没有频谱空洞**：500–800 Hz 保持平坦，250–320 Hz 有低中频体感；250 Hz、1 kHz 两侧都饱满，没有滤波式合成常见的「两带之间塌一个坑」。
- **没有 0.5–5 Hz 中速调幅**：调制谱实测 0.01–0.1 Hz 深度 24.7 / 31.2%，0.5–5 Hz 只有 **4.6 / 4.0%**（第 2 版是 18.4%），8–30 Hz 为 10.2 / 9.3%，30–50 Hz 6.8 / 6.8%。成簇没有把调制能量推回中速：20–50Hz 的包络变化只存在于雨滴层，整轨被雨幕主导，听不到「抽吸」。
- **没有共振峰、没有音高**：雨滴是带通噪声，不是阻尼正弦；Q 上限 4、共振上限 3 kHz，避免变成有音高的 ping。混响的梳状延迟改用互质采样数（见第三节），不会在 1 kHz 的整数倍上叠出窄峰。
- **「电流感」有可测的对应量**：把雨滴单独抽出来，150–350 Hz 的包络调制深度从 121.7% 降到 32.7 / 32.2%，200–500 Hz 从 100.7% 降到 24.9 / 24.6%。这是本轮最直接的验收数字；比整轨频谱更能解释听感。
- **刻意保留的合成痕迹**：120 秒的随机游走是**闭环**的，所以每一圈的风势、雨势、雨滴位置完全相同。要「永不重复」就得放弃循环；不接受的话，正确做法是做 3–4 条不同种子的 120s 版本随机轮播，而不是把单条做长。
- **种子可复现**：所有随机量来自 32 位种子（街 `20261027`、站 `20261034`）。同种子重跑逐字节一致（本轮已用 md5 复核两版），换种子得到另一条同风格但不同的雨。

## 二、时间 / 结构属性

### 循环性

- **无缝，120.000 秒**，`loop_mode = LOOP_FORWARD`，`loop_end = 5 292 000` 样本（引擎内实测）。
- **3 秒等功率交叉淡化**：先多渲染 3s 尾巴，再把尾巴与开头按 `sqrt` 曲线交叉淡化；淡化点在 0–6s 内搜索，选「首/末 0.5s 响度差最小、且不落在雨势深谷」的位置。
- **起点搜索保留了瞬态密度约束**：候选点的「起点 100ms」和「尾巴起点 100ms」的雨滴事件数，必须与全段均值相差不超过 50%。成簇以后单个 100ms 窗口本来就有 ±40% 的天然起伏（一簇 5–6 滴，均值 13 滴/100ms），所以两版都落在 **43%**——这不是失败，而是当前时间结构下能选到的最平窗口。
- **循环点不可察觉**，四条实测依据：
  1. 接缝处样本跳变 **0.00592（街）/ 0.00549（站）**，而全段相邻样本差的 p99.9 是 **0.06024 / 0.05991**——接缝只相当于正常高频内容的 9.8% / 9.2%，不构成事件。
  2. 首 0.5s 与末 0.5s 的 RMS 完全相同：街 **−32.36 / −32.36 dB**，站 **−32.00 / −32.00 dB**（差 0.00 dB），远低于 0.2 dB 的目标；接缝两侧不存在电平台阶。
  3. 交叉淡化用**等功率**（`sqrt` 而不是线性），中点不会掉 3 dB，不会在接缝附近压出周期起伏。
  4. **随机数不在接缝处重置**：所有事件时刻、幅度、声像是在整段 129.25s 渲染里连续抽取的，循环只是取其中 120s 的窗口；接缝两侧本来就是同一条随机序列的相邻片段。
- **为什么从「环形写入」改成「交叉淡化」**：v1 靠滤波状态绕一圈再滤一遍来闭环，波形连续，但首末 0.5s 的电平对不齐（实测差 0.56 dB），循环点会有可闻的音量台阶。v2 起改用 3s 等功率淡化 + 起点搜索，首末差压到 0.1 dB 以内。代价是开头 3s 的内容与尾巴有重叠，但雨声是稳态噪声，重叠听不出来。
- **随机游走如何闭环**：控制点的步长先减去均值，使一整圈的总位移为零；因此「最后一点 → 第一点」是正常大小的一步，不是跳变。混响延迟线、事件写入也全部按环形取模。

### 时间演化

- **风涌**：截止随机游走 70–300 Hz（0.25s 栅格，约 6s 平滑），振幅随机游走 **±6 dB**（0.5s 栅格，约 20s 平滑）。两条曲线独立，所以「变亮」和「变响」不总是同步。
- **雨幕**：
  - 慢包络：**−4.5…+4.5 dB**，0.5s 栅格、约 20–60s 平滑，负责「雨势段落」。
  - 微纹理：**8–30 Hz、±0.9 dB**，200 Hz 栅格。它只给雨沙一点快速质感，不参与雨势，也不形成可听的「抽吸」。
  - **没有 0.5–5 Hz 调幅**：第 2 版那条 0.5–5 Hz 带通噪声调制已经整段删除，第 3 版起不再有「沙沙呼吸」。
- **雨滴**：
  - 平均密度随机游走 110–155/s（街）/ 120–165/s（站），约 4s 平滑，控制的是**簇率**，不是逐滴间隔。
  - 时间结构：每簇 3–8 滴（均值 5.5），簇内 1–3ms；簇间隔 gamma(3)，均值 5.5/rate（约 33–50ms），截到 20–80ms。逐簇独立，不是固定周期。
  - 逐滴幅度再乘雨幕的同一条宏观包络，所以大雨势段的雨滴也更响；但簇率与幅度各自独立抖动。

### 瞬态事件

| 事件 | 商店街 | 加油站 | 说明 |
| --- | --- | --- | --- |
| 雨滴 | **15 957 个（133.0/s）** | **16 922 个（141.0/s）** | 平均密度 110–155/s（街）/ 120–165/s（站） |
| 雨滴簇 | **23.1 簇/s**，每簇约 **5.8** 滴 | **24.1 簇/s**，每簇约 **5.9** 滴 | 生成器统计每簇均值 5.5 滴 |
| 雨滴间隔 | 均值 **7.52 ms**，CV **1.91**，p99 70.2 ms，max 77.7 ms | 均值 **7.09 ms**，CV **1.89**，p99 68.0 ms，max 82.0 ms | 83% 的间隔 <8ms（簇内），其余是簇间 |
| 簇间间隔 | 均值 **33.6 ms**，CV 0.57，p99 75.5 ms | 均值 **31.5 ms**，CV 0.58，p99 75.0 ms | gamma(3)，截到 20–80ms |
| 雨滴时长 | 10.96–25.48 ms（均值 18.20） | 10.92–25.48 ms（均值 18.19） | 0.4–1ms attack + 3.5τ 指数衰减，τ=3–7ms |
| 雨滴带通 | 1000–3000 Hz，Q 2–4 | 1000–3000 Hz，Q 2–4 | 均匀随机，>3 kHz 为 0；带宽 250–1500 Hz |
| 雨滴幅度 | p50/p90/p99/max **0.25 / 0.63 / 2.05 / 2.20** | **0.24 / 0.63 / 2.06 / 2.20** | Pareto α=1.7，上限 median×10 |
| 雷 / 金属 / 车流 | 无 | 无 | 本轮规格明确移除 |

- **上限截断是可闻的取舍**：Pareto α=1.7 的理论尾部没有上限，最响的几滴乘上 +4.5 dB 雨势后会到床电平 +29 dB，标到 −23 LUFS 后真峰越过 0 dBFS。上限放在乘宏观包络**之后**（median×10），保证大雨势段的大滴仍能顶到上限，而不是被提前压平；代价是 p99 正好等于 max——约 1–2% 的雨滴被削到同一高度。
- **CV 1.9 是簇化的指纹**：均匀泊松是 1.01，聚集分布会明显大于 1；短间隔（<8ms）占 83%，长间隔（p99 70ms）只出现在簇与簇之间。听感上就是「一阵密、一下停」，而不是等间隔的脉冲串。
- **为什么每滴变长了**：3–7ms 的指数衰减 + 0.4–1ms 的 attack 让单滴成为 10–25ms 的「湿拍打」，而不是 1–5ms 的音爆发。长事件在簇内互相叠成一小片水声，簇间留白；这正是「雨落在雨里」的形态。

## 三、空间 / 心理声学属性

### 空间感

- **立体声**（2ch，44.1 kHz）。两版的立体声相关系数是 **0.522 / 0.524**，落在 0.45–0.6 的目标区间。
- **风涌半相关**：共同成分 0.8、左右独立成分 1.0，单层相关约 0.39。风本就弥散，保留一定宽度；但不至于在单声道折叠时把低频做没。
- **雨幕 60–70% 共用**：主雨沙的共同成分权重 1.25、左右独立成分 1.0，共同能量约占 **61%**；180–700 Hz 体感分量的共同权重 0.6。两版主体都是「同一场雨」，不是两条独立的雨拼在一起。
- **雨滴全随机声像**：每一滴在 −1…+1 之间独立取声像；同一簇内的雨滴也因此左右散开，给近场一点宽度。
- **早期反射**：三面一次反射，街 8.1 / 16.5 / 26.4 ms（359 / 727 / 1163 样本），站 11.0 / 19.5 / 29.2 ms（487 / 859 / 1289 样本），声像增益 0.42/−0.35、0.28/+0.45、0.17/−0.6，交替落在左右。
- **混响**：Schroeder 网络（**6 梳状 + 3 全通**），梳状延迟取互质采样数 **853 / 1019 / 1291 / 1627 / 1879 / 2333**（19.3–52.9 ms），全通 5 / 1.7 / 0.8 ms；湿声再经 3.2 kHz 低通。设计 RT60 0.44s / 0.62s，实测 0.35s / 0.50s；预延迟 8 / 11 ms；湿声目标 −16 dB（实测相对 send −16.7 / −15.4 dB）。
- **为什么用互质采样数**：v1 的梳状延迟取整数毫秒，所有延迟共享 1 ms 周期，会在 1k / 2k / 4k / 6k 上叠出一串窄峰——雨幕变暗后这些峰就露出来了。改成互质采样数后，峰值不再落在同一个频率栅格上，自动检测无共振峰。
- **风涌不送混响**：低频进混响会糊成一片，失去「空气在动」的清晰度。

### 距离感与包围感

- **「身处雨中」，不是「隔窗听雨」。**
- 依据：雨幕在 250 Hz–5 kHz 有连续能量，2 kHz 是峰，雨滴的 1–3 kHz 近场拍打仍在；8 kHz 以上虽然砍了 8–19 dB，但那是去掉「玻璃碴子」的硬，不是把整条雨推远。隔窗听雨会同时砍掉 500 Hz 以下和 2–4 kHz，只剩闷响——这里没有那样做。
- **近处雨滴靠重尾和簇突出**：层 RMS 只有 −12 dB（相对雨幕），峰值因数约 **28.8 / 28.5 dB**；p99 是 p50 的 **8.2 / 8.6 倍**，最大的单滴比整轨 RMS 高约 **17 dB**。少数大点仍能明确高过雨幕，形成「啪嗒」的近场细节。
- **层 RMS 比第 3 版高 1dB，但峰值更低**：−13 → −12 dB 是补偿单滴变长、事件变少后的能量；峰因数从 34 / 33 降到 28.8 / 28.5 dB，最大单滴的峰值反而比第 3 版低约 4dB。这不是把雨滴做响，而是把「尖」换成「宽」。
- **近场是成簇的，不是连续的**：23.1 / 24.1 簇每秒，每簇 5–6 滴、10–20ms 内打完，然后留 33ms 左右的空隙。第 3 版 213/s 的连续近场细节被替换成「小阵雨」，这是本轮听感变化的来源；密度低了一半，但事件不再等间隔。
- **中低频有实体**：250–320 Hz 的宽体感让雨落在地面/顶棚上的「体积」回来了，不是一层飘在空中的白噪声；500–800 Hz 保持平坦，不会像 500/630 那样糊成「嗡嗡」的腔。

### 情绪基调

- **基础情绪：沉静、微凉、偏中性**。没有音乐性和谐，没有可辨认的旋律，雨沙是中性的宽带噪声。
- **「微凉」不再靠高频刺**：8k 以上被压掉，凉意来自 1–3 kHz 的湿空气感与 8k 以上的空气感，不是 4k/8k 的「冰碴子」。250–320 Hz 的低中频体感给了一点点温度，整体不往温暖的方向拉太多。
- **没有雷的紧张点**：本轮规格不含雷。情绪曲线靠雨势段落（LRA 8.3 / 8.6）维持「活着」的感觉，而不是靠事件推进。
- **雨势段落是叙事层，簇是纹理层**：20–60s 的慢包络让雨有「下大一阵、又收小」的起伏；20–80ms 的簇只负责近场细节的疏密，不会形成可听的节奏周期。

## 四、合成 / 技术属性

### 声源构成

| 层 | 做法 |
| --- | --- |
| `wind` | 白噪声 → 时变低通（截止 70–300 Hz 随机游走，0.25s 栅格）→ 20 Hz 高通 → 1 阶 420 Hz 低通；振幅 ±6 dB 独立随机游走 |
| `rain` | 白噪声 → 250 Hz 1 阶高通 → 320 Hz/Q1.3 +1.2 dB → 650 Hz/Q1.0 −1.5 dB → 2 kHz/Q1.0 +2.5 dB → 4 kHz/Q0.9 −4.0 dB → 4 阶 5.2 kHz 低通 → 7 kHz/Q0.7 −3.0 dB；另叠 180–700 Hz 体感（320 Hz +1.0 dB，BODY 0.75）；慢包络 −4.5…+4.5 dB + 8–30 Hz ±0.9 dB 微纹理 |
| `drops` | 每个雨滴：白噪 × 升余弦 attack（0.4–1 ms）→ 带通（1–3 kHz，Q 2–4）→ 指数衰减（τ=3–7 ms）+ 0.5 ms 尾部淡出；成簇到达（3–8 滴/簇、簇内 1–3 ms、簇间 20–80 ms）；Pareto（α=1.7）幅度、随机声像、上限 median×10 |
| `space` | 三面早期反射 + 6 梳状 / 3 全通 Schroeder 尾 + 3.2 kHz 湿声低通；只处理雨幕 + 雨滴 |

**不含**：FM 合成、采样拼接、共振峰合成、振荡器。

### 调制方式

- **随机游走 → 滤波截止 / 振幅 / 慢雨势 / 簇率**：所有慢变化都是环形随机游走，不是正弦 LFO。
- **8–30 Hz 带限噪声 → 微纹理**：只做 ±0.9 dB 的快速抖动，深度不足以形成「抽吸」；**没有 0.5–5 Hz 调制层**。
- **gamma(3) 簇间隔 + 均匀簇内间隔 → 事件时间结构**：不是泊松稀疏化。簇率由随机游走控制，每簇滴数 3–8 均匀随机，簇内 1–3ms；这样平均密度可以低，但局部密度始终是「一串」。
- **带通噪声 + 指数包络 → 单滴音色**：不用两极点谐振器的脉冲响应，避免出现固定频率的阻尼振荡；Q 2–4 的带宽足以把「滴」摊成「拍」。
- **块内系数固定**：时变低通每 128 样本（约 2.9 ms）换一次系数，块间无 zipper 噪。
- **母版限幅也是环形的**：检测器、延迟线都按模回绕，状态先跑一圈暖机，接缝不会出现增益台阶；本版输入峰值低于阈值，限幅器实际不介入。

## 复现与调整

生成器是一次性工具，不进仓库（工程「零外部资产」的约定）。脚本在
`.workbuddy/gen/rain120.mjs`：

```bash
cd .workbuddy/gen
node --max-old-space-size=6144 rain120.mjs street  ../../audio/street_rain_loop.wav  20261027 -26.30
node --max-old-space-size=6144 rain120.mjs station ../../audio/gas_station_rain_loop.wav 20261034 -26.20
```

不带增益参数时输出 32-bit float（峰值可超过 1）：先用 `ffmpeg -af ebur128` 量出 I，
再用 `−23 − I` 作为增益重跑一次；16-bit 路径会自动过环形限幅器。这条路径不经过 ffmpeg，不会带 LIST 元数据块。

常用旋钮（都在 `buildWind()` / `buildCurtain()` / `buildDrops()` / `spaceWet()` / `pickLoopOffset()` / `limitLoop()` 里）：

| 想要 | 动哪里 |
| --- | --- |
| 改三者比例 | 主流程的层增益目标：风涌 −3 dB、雨滴 −12 dB（雨幕是 0 dB 基准） |
| 雨滴更密/更疏 | `buildDrops()` 的 `rateMin` / `rateSpan`（街 110/45，站 120/45）；注意这是**平均**密度，不是均匀撒点 |
| 雨滴簇更明显 | 每簇滴数 `3 + Math.floor(rnd() * 6)`；簇间 `5.5 / rate` 与 gamma(3)，截断 `20–80ms`；簇内 `0.001 + rnd() * 0.002` |
| 雨滴更重尾 | Pareto `alpha`（1.7）与 `cap`（median × 10） |
| 雨滴更亮/更暗 | `fc = 1000 + rnd() * 2000`（1–3kHz） |
| 雨滴更「拍」/更「滴」 | attack `0.0004 + rnd() * 0.0006`、decay `0.003 + rnd() * 0.004`；decay 越长越像水声，越短越像音头 |
| 风更明显 | `gWind` 目标，或截止范围 `70 + 230 * ...`、包络 `dbGain(-6 + 12 * ...)` |
| 雨幕更暗/更亮 | `shapeCurtain()` 的 2 kHz peak、4 kHz peak、`lowpass4Causal(5200)`、7 kHz peak |
| 中频更满/更薄 | `shapeCurtain()` 的 320 Hz peak、`BODY`（0.75）、`shapeBody()` 的 320 Hz peak |
| 微纹理更深/更浅 | `buildCurtain()` 里 `0.9 * m` 的深度，或 `microCurve()` 的 8–30 Hz 带宽 |
| 雨势段落更明显 | `buildCurtain()` 的 `macroWalk`（81 点平滑）与 `-4.5 + 9 * ...` 范围 |
| 空间更长 | `spaceWet()` 的 `rt60`（街 0.44 / 站 0.62），湿声 −16 dB |
| 接缝更稳 | `FADE_SEC`（3s）与 `SEARCH_SEC`（6s）；`pickLoopOffset()` 的瞬态密度阈值（当前 50%） |
| 母版更保守 | `limitLoop()` 的 `thresholdDb`（−1.5）、`lookMs`（2）、`releaseMs`（180） |
| 换场地味 | 换种子（但会得到另一条雨，不再是当前入库版本） |
| 改时长 | `DUR`；簇率、混响环形长度按 `DUR` 算，但控制点栅格（0.25s / 0.5s）是写死的，改完必须重测接缝 |
