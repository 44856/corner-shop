# 雨声环境音规格

> 对象：`audio/street_rain_loop.wav`（商店街）、`audio/gas_station_rain_loop.wav`（国道加油站）
> 生成：2026-10-27，纯电子合成，无采样。全部数值为**实测**，测量方法见文末。
> 用途：两个场景的 `&"rain"` 命名声道（见 [`音频总线.md`](音频总线.md)）。

两条是同一套骨架的两个场地变体，不是同一条加参数：

| | 商店街 | 加油站 |
| --- | --- | --- |
| 场地 | 楼与楼之间的湿街道，两侧有卷帘门、雨棚、空调外机 | 开阔前场 + 铁皮顶棚（顶棚离头约 2m） |
| 雨的落点 | 混凝土为主，零星金属 | 顶棚金属为主，前场混凝土为辅 |
| 空间 | RT60 较短（街道被两侧立面夹住） | RT60 较长（顶棚 + 开阔地，反射更远） |

## 一、声学 / 物理属性

### 频谱特征

能量分布（倍频程，相对 1kHz，dB）：

| 频段 | 31.5 | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 商店街 | −8.5 | −5.4 | −2.2 | −1.8 | −0.7 | **0** | −0.2 | **+3.2** | **+2.6** | −7.8 |
| 加油站 | −5.6 | −2.2 | −0.6 | −0.8 | 0.0 | **0** | −1.0 | **+3.3** | **+3.4** | −6.2 |

- **雨沙是主体**：2–8kHz 比 1kHz 高 3dB 左右，正是"沙沙"那一段（按规格刻意保留）。
- **风在 200Hz–2kHz**：250Hz–1kHz 与 1kHz 基本齐平，没有一个独立的"风峰"，因为风是宽带被扫的过程，不是一条固定的带。
- **低频**：63–125Hz 只有 −5 ~ −2dB，够"空气在动"，不会盖住对白/音效。30Hz 以下陡降（−8.5dB @31.5），没有多余的次声垃圾。
- **无共振峰**：40Hz–16kHz 内没有任何窄峰高出 ±1/3 倍频程中位数 6dB（自动检测，见文末）。顶棚的金属声是宽带冲击，不是驻波。

### 动态范围

| | 商店街 | 加油站 |
| --- | --- | --- |
| 整体响度（EBU R128） | **−23.0 LUFS** | **−23.0 LUFS** |
| 真峰 | −9.4 dBFS | −9.6 dBFS |
| RMS | −28.0 dBFS | −27.9 dBFS |
| 峰值因数（peak−RMS） | 18.6 dB | 18.3 dB |
| 响度范围 LRA | 2.7 LU | 2.9 LU |
| 动态余量（−23 − 真峰） | 13.6 dB | 13.4 dB |

- **雨势与阵风的缓慢起伏**：剔除雷的时段后，逐秒 RMS 的 p10–p90 只有 **3.7 dB**——是"缓慢呼吸"，不是忽大忽小。
- **雷是瞬态高峰**：含雷的那一秒 RMS 比中位数高 **+5.0 dB**（加油站 +3.4 dB），峰值 −9.4 dBFS 就是雷打出来的。全曲最响的 5 秒全部集中在雷与过车处。
- 13.6dB 的余量是有意留的：场景里还要叠门铃、服务铃、低频，母版不留头就没法混。

### 信噪比与纯净度

- **没有录音底噪**：不存在话筒自噪、电流声、空调嗡鸣。基底（bed 层）是有意铺的粉红化噪声（−36.8dB RMS），不是设备噪声。
- **没有频谱空洞**：各层频段互相交叠（bed 60Hz–6k / 风 200Hz–2.1k / 雨 2k–8k），因此没有滤波式合成常见的"两带之间塌一个坑"。2.2kHz 处原本有一个 −1dB 的凹陷，用宽峰补平了。
- **刻意保留的合成痕迹**：阵风包络以 **90 秒为周期**，即每一轮循环的风势完全相同。这是无缝循环的代价——要"永不重复"就得放弃循环。0.1% 的人会在第二圈察觉，这被认为可接受；不接受的话，正确做法是做 3–4 条 90s 版本随机轮播，而不是把单条做长。

## 二、时间 / 结构属性

### 循环性

- **无缝，90.000 秒**，`loop_mode = LOOP_FORWARD`，`loop_end = 3 969 000` 样本（引擎内实测）。
- **循环点不可察觉**，三条实测依据：
  1. 接缝处样本跳变 0.0082（街）/ 0.0393（站），而全段相邻样本差的 p99.9 是 0.0871 / 0.0904——接缝处的变化**落在正常高频内容的分布里**，不构成事件。
  2. 首 0.5s 与末 0.5s 的 RMS 差 **0.03 dB / 0.07 dB**，接缝两侧不存在电平台阶。
  3. 实现上没有用交叉淡化（交叉淡化会在接缝附近压出周期起伏，听起来像呼吸），而是环形写入 + 滤波状态绕一圈再滤一遍，首尾天然连续。

### 时间演化

- **雨势**：90 秒内走一轮"略强 → 略弱 → 回稳"，幅度 ±12%（`1 + 0.10·sin(2πt/90) + 0.05·sin(6πt/90)`），周期整除循环长度，所以接缝处不跳。
- **阵风**：三个不可通约的整数周期（1/90、2/90、4/90 Hz）叠加后取 1.6 次幂，90 秒内约 4 次起伏，听感上不重复；阵风同时驱动**截止频率**（350Hz ↔ 1.8kHz）和**低频风涌的增益**。
- **随机化**：雨滴不是均匀撒点，而是按雨势做拒绝采样——雨大的时段自然更密；位置、音高、衰减、声像全部独立随机。

### 瞬态事件

| 事件 | 商店街 | 加油站 | 间隔分布 |
| --- | --- | --- | --- |
| 雨滴击打 | 3614 个（**40.2/s**） | 1185 个（13.2/s，前场混凝土） | 泊松式，受雨势调制 |
| 金属击打 | 320 个（3.6/s，卷帘门/雨棚/外机） | 745 个（8.3/s，顶棚） | 均匀随机 + 雨势加权 |
| 雷 | 2 次（13.5s、61.0s） | 2 次（21.0s、68.5s） | 间隔 47.5s；跨接缝 42.5s |
| 过车 | 4 次（5.0/28.4/52.0/76.5s） | 4 次（同上） | 约 23–24s |

雷刻意错开到不同的秒数，这样从一个场景走到另一个场景时不会听到同一记雷。

## 三、空间 / 心理声学属性

### 空间感

- **立体声**（2ch，44.1kHz）。中低频居中、高频散开：立体声相关系数 **0.164（街）/ 0.216（站）**，属于"宽但不空"——声场宽度中等偏宽，单声道折叠不会塌。
- **早期反射**：三面一次反射，8 / 16 / 26 ms（街），11 / 19 / 29 ms（站），分别来自对面立面、地面、侧墙，交替落在左右。
- **混响**：Schroeder 网络（4 梳状 + 2 全通），**设计 RT60 0.5s / 实测 0.41s**（街）、**设计 0.7s / 实测 0.58s**（站）。加油站更长，因为顶棚把声音挡回来。湿声电平 −15 dB。
- 没有做"屋檐下"的极端短 RT60——两个场景都是**站在雨里**，不是一个躲雨的人听到的声音。

### 距离感与包围感

- **"身处雨中"**，不是"隔窗听雨"。
- 依据：近场粒子峰值比远场床的 RMS 高约 **13–14 dB**，粒子能逐个分辨；同时 63–250Hz 的低频床足够厚（−5 ~ −2dB），提供被包围的体积感。隔窗听感会表现为 4kHz 以上被砍掉一截、只剩 500Hz 以下——这里没有那样做。

### 情绪基调

- **基础情绪：沉静、微凉、偏中性**。没有音乐性和谐，没有可辨认的旋律，雨沙是中性的白噪。
- **雷提供稀疏的紧张点**：90 秒两记，第一记远（低通 80–90Hz、无爆裂），第二记近（120–140Hz、带 0.55s 的"裂"）。情绪曲线是"平静 → 一记远的 → 平静 → 一记近的 → 回到平静"。
- **合成的"均匀感"是刻意的**：真实暴雨的雨滴撞击是极度不均的，这里的密度被雨势包络抹平了一层，代价是损失一点野性，换来游戏里长时间不烦。

## 四、合成 / 技术属性

### 声源构成

| 层 | 做法 |
| --- | --- |
| `bed` | 白噪声 → 二阶低通（6k）+ 高通（60），粉红化，做"空气" |
| `rain` | 白噪声 → 2k 高通 + 8k 低通（加油站 2.2k–8.6k）；左右独立 + 30% 共用分量 |
| `wind` | 白噪声 → **时变低通**（截止随阵风 350Hz↔1.8kHz 扫动）→ 200 高通 → 2.1k 低通 |
| `windlow` | 白噪声 → 200 低通 + 30 高通，随阵风起伏 |
| `drops` | 颗粒合成：每个雨滴是一段 5 点噪声爆发过带通（Q 1.2–3.6，τ 2–13ms），按雨势做拒绝采样 |
| `metal` | 宽带冲击过 2.4–5.6kHz 带通（τ 3–15ms），**无振荡器**——用阻尼正弦会变成风铃 |
| `thunder` | 低通噪声（90/140Hz，叠一层 55Hz 次声）→ 手工包络（50ms 起音 / 22% 主体 / 长衰减）+ 近雷的 180Hz"裂" |
| `traffic` | 白噪声 → 低通 470–680Hz × 非对称高斯包络 + 慢速声像移动 |

**不含**：FM 合成、采样拼接、共振峰合成。

### 调制方式

- **LFO → 滤波截止**：阵风包络驱动 `wind` 的低通截止（每 128 样本换一次系数，约 2.9ms，块间无 zipper 噪）。
- **随机包络 → 事件密度**：雨滴密度由雨势 × 拒绝采样控制，不是固定间隔。
- **所有调制周期都整除 90 秒**，否则接缝处包络会跳。

### 格式参数

| | 值 |
| --- | --- |
| 容器 / 编码 | WAV / PCM 16-bit |
| 采样率 | 44 100 Hz |
| 声道 | 2（立体声） |
| 时长 | 90.000 s（3 969 000 样本/声道） |
| 响度 | **−23.0 LUFS**（EBU R128 / ITU-R BS.1770） |
| 真峰 | −9.4 / −9.6 dBFS |
| 文件大小 | 15 876 044 B（各），入 git-lfs |
| 导入 | QOA（`compress/mode=2`），循环由 `AudioBus` 在副本上设，不在导入里设 |

场景侧换算：素材 −23 LUFS，`hoshi_street` / `gas_station` 的 `db` 取 **−12.5**，有效电平 −35.5 LUFS；进店 −24.5、顶棚下 −18.5，保持原有 12dB / 6dB 落差。

## 复现与调整

生成器是一次性工具，不进仓库（工程"零外部资产"的约定）。要重做或改参数，脚本在
`.workbuddy/gen/rain90.mjs`：

```bash
node --max-old-space-size=3072 rain90.mjs street  -0.9 out_street.wav   # 商店街
node --max-old-space-size=3072 rain90.mjs station -0.4 out_station.wav  # 加油站
```

常用旋钮（都在 `buildStreet()` / `buildStation()` 里）：

| 想要 | 动哪里 |
| --- | --- |
| 雨更大/更小 | `rain` 层的增益（0.062 / 0.058），别动量，量会同时改变信噪比 |
| 更少"沙沙" | `rain` 层的低通上沿（8k → 6k），不是整体降电平——降电平不改比例 |
| 风更明显 | `wind` 增益与阵风深度（`0.30 + 0.70 * gust`） |
| 雷更少 / 更远 | `thunder` 的 `amp` 与 `lpHz`（越低越远） |
| 更长的混响 | `space()` 的 `rt60`（街 0.5 / 站 0.7） |

## 测量方法

| 指标 | 方法 |
| --- | --- |
| 响度 / 真峰 / LRA | `ffmpeg -af ebur128=peak=true` |
| 倍频程分布 | `.workbuddy/gen/analyze.mjs`（自带 radix-2 FFT，32768 窗，50% 重叠） |
| 共振峰 | `.workbuddy/gen/probe90.mjs`：比 ±1/3 倍频程中位数高 6dB 的窄峰 |
| 接缝 | 接缝样本跳变 vs 全段相邻样本差的 p99.9；首末 0.5s RMS 对比 |
| RT60 | 把单位脉冲喂进同一套混响网络，Schroeder 反向积分到 −60dB |
| 事件密度 | 生成器直接统计被接受的事件数 |
