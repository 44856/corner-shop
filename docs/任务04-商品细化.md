# 任务 04：便利店商品细化

分支：`feature/store-goods-detail`

## 目标

上一期的店内是「能走进去」，但货架上摆的是**随机尺寸的彩色方块**，冷柜里是
**贴在发光板上的一排圆柱**。这一期只做一件事：让商品在 1–2m 的观看距离上
能被认出来是什么，并且摆放方式像便利店。

不改布局、不改碰撞范围、不改交互点位置 —— `layout()` 一个数字都没动。

## 改前的三个硬伤

| 现象 | 原因 | 证据 |
| --- | --- | --- |
| 货架看起来是空的，只有几条彩边 | 商品底面在 `FLOOR + 0.14`（0.31m），层板顶面在 `FLOOR + 0.425`（0.595m），**整排埋在层板里** | 三层都是固定 −0.285m 的偏移，不是随机误差 |
| 冷柜里的商品像贴在白板上 | 柜体是一个实心盒子，前面又贴了一块发光板；商品摆在 `z1 + 0.07`，其实在柜体外面 | 发光板是 `depth_draw_opaque`，实心不透明 |
| 杂志架只有几条彩边 | 架体是一整块 0.45×1.1×1.4 的实心方块，杂志摆在方块内部（`x = 中心 + 0.15`） | 从 +X 方向看，杂志整个在盒子里 |

这三条都是「看起来有、实际看不见」，不是风格问题。

## 商品库：`scripts/goods.gd`

新建一个纯静态库，和 `kit.gd` 同一定位：无状态、只依赖原语、不做布局决策。

约定：**正面 = 本地 +Z，底面在 y = 0，原点在底面中心**（和角色「脸朝 +Z」一致）。
所有尺寸是真实尺寸，不是随手缩放的。

| 类型 | 尺寸（m） | 网格数 | 辨识点 |
| --- | --- | --- | --- |
| `bottle` | 0.06 × 0.22 | 5 | 直筒身 + 收口肩 + 颈 + 瓶盖 + 标签圈 |
| `can` | 0.064 × 0.12 | 3 | 银色顶圈那一道亮边 |
| `cup`（杯面） | 0.098 × 0.13 | 3 | 上宽下窄的锥台 + 盖 + 腰封 |
| `bowl`（碗面） | 0.136 × 0.155 | 3 | 比杯面矮胖、盖更宽 |
| `bag`（膨化袋） | 0.115 × 0.185 | 4 | 上下封边比袋身宽 8mm（枕形） |
| `onigiri`（饭团） | 0.095 × 0.105 | 3 | 三棱柱 + 海苔 + 口味标 |
| `bento`（便当） | 0.15 × 0.05 | 4 | 黑盘 + 透明盖 + 顶面标签 |
| `bread` | 0.14 × 0.077 | 2 | 扁球袋身 + 封口夹 |
| `tissue` | 0.12 × 0.065 | 2 | 顶面抽口 |
| `cigarette` | 0.058 × 0.085 | 3 | 白盒 + 品牌色块 + 警示条 |
| `carton`（通用小盒） | 0.075 × 0.11 | 2 | 立式小盒 + 正面标贴 |

两条约束写进了文件头：

- **层间净空只有 0.34m**，超过 0.26 的东西放不进上层；
- 商品一律不带描边（`line: 0.0`）。几百个小物件各挂一个 outline pass，
  代价比收益大，而且 1m 外的描边只有 1px，看不出来。

`kit.gd` 补了一个 `prism()`：顶点朝上、沿 +Z 挤出。没用 `PrismMesh` 是因为
它的朝向由引擎定死，饭团每摆一个都得再猜一次欧拉角。

## 排面（planogram）

`store.gd` 顶部三份常量，按「这一层摆什么」描述，字符串就是 `goods.gd` 的类型名：

| 方案 | 第 1 层 | 第 2 层 | 第 3 层 |
| --- | --- | --- | --- |
| `PLAN_FOOD` | 杯面 / 碗面 | 罐头 / 进口饼干 | 饼干 / 薯片 / **缺一格** / **倒下的泡芙盒** |
| `PLAN_SNACK` | 薯片 / 面包 | 饼干 / 薯片 | 面包 / 饼干 |
| `PLAN_HOUSE` | 纸巾 / 小盒 | 小盒 / 纸巾 | 纸巾 / 小盒 |

内容对齐 `store_walk.gd` 里 `_on_rack` 的三句台词 —— 玩家看到的和读到的要是同一批货：

- 「方便面、罐头、两排没什么人买的进口饼干」→ `PLAN_FOOD` 的前两层；
- 「货架第三层空了一格。价签还在，东西没了。」→ 第三层那个 `""`，
  价签照样画（`price_tag` 在 `continue` 之前）；
- 「你顺手把一盒倒下的泡芙扶正」→ `"down"`，一个绕 Z 转 90° 躺倒的盒子。

排面密度按 0.155m 一格算：1.55m 的货架 10 格。原来按 0.21 算只有 7 格，
商品之间能塞下两个手指，看着像没上货。

## 货架结构

原来的货架只有三块悬空横板 + 一块压顶的挡板，侧面看是「飘」的，背面完全透空。
现在补齐了：底座 / 两端立板 / 中隔板（兼背板）/ 三层板 / 前沿价签轨 / 踢脚板 /
顶部挡板 + 分类字 + 分类色条。

几个数字是量出来的，不是拍的：

- **顶部挡板下沿 1.57m**。原来压到 1.29m，而顶层商品顶在 1.28–1.50m ——
  整排被挡得只剩一条边；
- **中隔板用浅色**。深色背板会让每层变成黑洞，商品像浮在暗格里；
  真店的货架背板是白色 / 浅灰洞洞板；
- **端板用深色**。浅色端板从过道东头看过去是一整块米色墙，把排面全挡了；
- **中层补一排背库存**（`pz − side × 0.115`）。斜着走的时候，货架纵深
  不会是一片空板。只补中层 —— 上层俯视看得见，下层被前沿挡住。

可玩版是双面货架（进店先看南面，绕过去是北面），展示版只做 +Z 面，
省一半节点。

## 冷柜

从「实心盒子 + 前贴发光板」改成**开口的壳**：背板 / 左右侧板 / 顶底 / 四层搁板，
商品真的放在柜内，前面装四扇玻璃门（门框 + 玻璃 + 竖把手）。

- 层板顶面 0.42 / 0.86 / 1.30 / 1.74，每层 8 个排面；
- 从下往上：便当 → 饭团 → 瓶装 → **罐装**。最上层是罐装，
  和 `_on_fridge` 的「最上层那排罐装咖啡」对得上；
- 层板下沿一条自发光灯条（`glow 0.85`），背板一块弱背光（`glow 0.55`）——
  冷柜的「亮」来自每层的灯管，不是一块大发光板；
- 玻璃 `alpha 0.05`、`edge 0.25`，看得清里面，又能看出有一层玻璃。

## 杂志架 / 堆头 / 香烟架 / 台面

- **杂志架**：背板 + 三层搁板 + 前挡条，杂志斜靠 12°、封面朝 +X。
  5 本/层 × 3 层，刊名是 ASCII（`WEEKLY` / `MODE` / `CAR` / `GAME` / …）——
  `Label3D` 走的是默认字体，没有 CJK 字形，写中文会变成方块。
- **堆头**：纸箱底座 + 高出商品一截的挡板（`SALE` / `¥3.9`）+ 两排杯面/瓶装。
  挡板原来朝 −Z，从街上和进门第一眼看到的都是纸板背面。
- **香烟架**：三排 × 8 盒，面朝 −X（过道方向）。
- **收银台**：加了一台刷卡机、一本摊开的杂志。HUD 台词里说
  「收银台上那本翻到一半的杂志」，原来台上并没有 —— 说了就得有。

## 灯光

三盏主灯挂在 2.5m，光被层板挡死，货架格子里是一片黑。补了两盏**和货架同高**
（1.12m）、**不投影**、范围 2.2m 的补光：只照亮排面，不改变整体氛围，
也不会漏到街上。能量从 0.55 收到 0.30 —— 0.55 的时候标签直接烧白。

## 碰撞

顺手修了两处「碰撞盒和视觉盒子不同心」：

| 物体 | 改前 | 改后 |
| --- | --- | --- |
| 促销堆头 | 中心比视觉高 0.28m（撞在空气里） | 同心 |
| 杂志架 | 按 1.10m 高算，视觉现在是 1.20m | 1.20m |

## 性能

可玩版场景：**1904 个节点 / 1341 个 MeshInstance3D / 125 个 Label3D**
（改前约 900 个 Mesh）。商品全部是低段数原语（圆柱 8–12 段），
没有新增材质实例（`kit.toon` 缓存按参数复用），没有新增灯光阴影。

## 已知限制

- 商品是「包装剪影」而不是包装设计：没有贴图、没有品牌、没有条码。
  这个距离能读出「瓶 / 罐 / 杯 / 袋 / 三角饭团」，读不出是什么牌子；
- 排面是静态的，不会补货、不会被拿空（缺货那一格是写死在排面里的）；
- 展示版（`main.tscn`）的货架宽 4.6m，排面封顶 20 格，格子之间比可玩版松；
- 冷柜门是死的，碰撞是整块实体 —— 交互文案仍然是「拉开冷柜」，但拉不开。
