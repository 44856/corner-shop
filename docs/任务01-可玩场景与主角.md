## 0. 先读这一节：本工程的写法约定

**这个工程没有一个编辑器摆出来的场景。** 整个仓库只有：

```
scenes/main.tscn        6 行，一个空 Node3D + 挂一个脚本
scripts/main.gd         所有东西都在 _ready() 里用代码生成
scripts/street.gd       街道几何
scripts/store.gd        便利店几何
scripts/props.gd        道具几何
scripts/kit.gd          建模工具库（体块/圆柱/材质缓存）
scripts/actor.gd        角色（已实现，见第 3 节）
scripts/cutscene.gd     开场动画时间轴
shaders/                全部自定义着色器
assets/characters/      gaia.glb（主角模型）
audio/                  程序化生成的雨声/雷声/底噪
```

**新场景必须遵守同样的写法**：`.tscn` 只放一个根节点 + 一个脚本，几何体全部由脚本生成。
**不要在编辑器里拖节点、不要手写大段 Transform3D。**

### 2.3 本任务要加的一件事：平色模式

**主角不使用 VRM 自带的贴图**（那 28 张解压出来的 PNG 共约 10 MB，风格也和本工程的平色三渲二不搭）。

要做的是：给 `actor.gd` 加一个开关，平色时用 `scripts/kit.gd` 里现成的 `toon()`：

```gdscript
## 是否使用平色（true = 不用 VRM 贴图，用 toon.gdshader 上纯色）
@export var use_flat_colors := true
```

按 **surface 原材质名做包含匹配**取色：

| 材质名关键字 | 颜色 | 说明 |
|---|---|---|
| `Body_00_SKIN` / `Face_00_SKIN` | `#e8c4a8` | 皮肤 |
| `Hair` | `#3a3f52` | 头发 |
| `EyeIris` | `#6f8fb8` | 瞳孔 |
| `EyeWhite` | `#f0f0f2` | 眼白 |
| `FaceBrow` / `FaceEyeline` / `FaceMouth` | `#2a2a33` | 五官 |
| `CLOTH` | `#4a5568` | 衣服 |
| 其它 | `#808080` | 兜底 |

实现提示：`kit.gd` 的 `toon(color, params)` 会返回一个 `ShaderMaterial` 并**自动挂好描边**，
`params` 里 `line` 控制描边粗细。建筑用 `line = 0.011`，**角色用 0.006**（太粗会糊住五官）。

> 顺带：开场动画里那个角色（`scripts/main.gd` 的 `_setup_actors()`）也一起切到平色，
> 保证穿越前后是同一个人同一套画风。

## 3. 平色之后的材质注意点

- 头发/睫毛/眉毛原本是靠贴图的 alpha 镂空的。平色之后**没有 alpha**，
  会出现"眉毛变成实心黑块"的问题。
- 处理办法：这几类 surface 给一个**略透明的深色**，或者直接接受（远景看不出来）。
  先按接受的方案做，若效果太糟再说。

## 4. 玩家控制器：移植，不要重写

`F:\demo1\dev\scripts\player.gd` 里有一个**已经实测可用**的第三人称控制器：

- CharacterBody3D + SpringArm3D 相机（贴墙自动回缩）
- 跳跃手感用「跳跃高度 + 到顶耗时」反推重力，上升/下降用不同重力
- coyote time + jump buffer + 可变跳跃高度
- **自动上台阶**（细粒度探针扫描，实测能爬 0.25 m 台阶）
- 身体朝向只做水平旋转

**移植到 `scripts/player_controller.gd`，然后删掉这些依赖**：

| 要删的 | 原因 |
|---|---|
| `Dialogue.is_active()` 的两处判断 | corner-shop 没有 `Dialogue` autoload |
| `Input.is_action_pressed("toggle_step_up")` 等动作 | 见下条 |

### 4.1 输入怎么处理（重要）

**不要改 `project.godot`。** 这个工程一个 InputMap 动作都没有。

用代码注册，符合本工程"全程序化"的风格：

```gdscript
func _ensure_actions() -> void:
	for spec in [
		{"name": "move_forward", "keys": [KEY_W, KEY_UP]},
		{"name": "move_backward", "keys": [KEY_S, KEY_DOWN]},
		{"name": "move_left", "keys": [KEY_A, KEY_LEFT]},
		{"name": "move_right", "keys": [KEY_D, KEY_RIGHT]},
		{"name": "jump", "keys": [KEY_SPACE]},
		{"name": "sprint", "keys": [KEY_SHIFT]},
	]:
		if InputMap.has_action(spec["name"]):
			continue
		InputMap.add_action(spec["name"])
		for k in spec["keys"]:
			var ev := InputEventKey.new()
			ev.physical_keycode = k
			InputMap.action_add_event(spec["name"], ev)
```

在 `_ready()` 里调用一次。

### 4.2 朝向要对齐

模型**脸朝 +Z**。控制器里如果有 `visual.rotation.y = atan2(dir.x, dir.z)` 这种写法，
它的含义是"让 +Z 指向移动方向" —— **正好匹配，不需要额外旋转**。

如果画面里角色是倒着走的，说明你加了多余的 180°，去掉即可。

## 5. 场景内容（blockout 即可，不做美术）

### 5.1 必须有的

| 内容 | 参数 |
|---|---|
| 地面 | 60 × 60 的 `StaticBody3D` + `BoxShape3D`，顶面在 `y = 0` |
| 玩家出生点 | `(0, 0.05, 0)` |
| 灯光 | 一盏 `DirectionalLight3D`，开阴影 |
| 环境 | 一个 `WorldEnvironment`（天空 + 轻雾即可，不必复刻夜雨） |
| 相机 | 由玩家控制器自带（SpringArm + Camera3D） |

### 5.2 验证用的几何体

用 `CSGBox3D` + `use_collision = true`（`kit.gd` 里有现成的 `box()` 工具函数）：

| 物体 | 尺寸 | 目的 |
|---|---|---|
| 楼梯 6 级 | 每级高 **0.25 m**、深 **0.45 m**、宽 3 m | 验证自动上台阶 |
| 高台 | 高 **1.5 m** | 验证跳跃上限 |
| 墙 | 高 3 m | 验证不能翻越 |

> ⚠️ **楼梯尺寸不要改。** 现有上台阶逻辑对「台阶深度接近碰撞半径（0.4 m）」极敏感，
> 0.45 m 是实测能爬的临界值。改了必须回归。
>
> ⚠️ 台阶高度 0.25 m 也**不要**改成 0.5 m 以上——超过 `max_step_height`（0.45 m）就得上跳。

### 5.3 不要有的

雨、便利店、街道、后巷、霓虹、涟漪、开场动画。
**这个场景和 `main.tscn` 是两个独立场景，互不加载。**
