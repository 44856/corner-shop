# 任务 03：马路车祸事件（进过店 → 下马路 → 右侧来车）

分支：`feature/truck-hit`　前置：`feature/store-walk-in`（可玩版）

## 目标

在可玩版上续一段事件：人物**先进过便利店**，再走到马路上时，右侧驶来一辆
大货车撞向人物。货车从台面外开进来，**超出台面的部分不渲染** —— 微缩底座是
一块 11.2m 见方的「切片」，车不能半截浮在底座外面的空气里。

## 触发链

```
进店（区域判定 "in"）→ notify_store_entered()   ← 只记第一次
      ↓
走出店门、下到南侧车行道（z > 2.05，且没锁输入）
      ↓
fire()：锁输入 → 0.42s 预警（喇叭先从画面外传来）→ 生成货车
      ↓
车头追上人 → 命中 → 击飞 / 白闪 / 镜头抖 / 闷响 → 收黑
      ↓
黑场里复位到出生点 → 淡入 → 一句 toast
```

- 触发区只算**南侧车行道**（人行道是 L 形，z 1.9 以南是沥青）。
  西侧那条窄路不触发：车得从北边店里开出来才撞得到，说不通。
- 前置条件挂在 `_zone_at()` 的真实区域判定上，不是测试里手动置位。
- 一次性：`_state` 走到 `DONE` 之后不再触发，撞完可以放心在马路上走。

## 车怎么开进来

`scripts/truck.gd` 全程序化搭一台 6.2 × 2.16 × 2.86m 的厢式货车（车头 +X，
前轴 + 双后轴、腰线、尾门、后视镜、双前照灯 SpotLight、刹车灯）。

出场点离台面边缘 9m，13m/s（≈47km/h）沿 X 轴冲进来。**裁剪靠着色器**：

| 文件 | 改动 |
| --- | --- |
| `shaders/toon.gdshader` | 新增 `clip_on / clip_min / clip_max`，片元世界坐标越界即 `discard` |
| `shaders/outline.gdshader` | 同一组参数 —— 车身裁了、描边壳还在，等于给空气描边 |
| `shaders/glow.gdshader` | 灯板也要裁，否则尾灯会亮在台面外面像一盏悬空的红灯 |
| `scripts/kit.gd` | `toon_clipped()` / `glow_clipped()`：复制一份材质并打上裁剪参数 |

三个 shader 的裁剪默认关闭（`clip_on = false`），其余材质完全不受影响。

**为什么必须逐材质独立**：`kit.toon()` 是按「颜色 + 参数」缓存的，
裁剪参数如果写在缓存材质上，会顺带把整条街一起裁掉。所以货车走
`toon_clipped()`，`duplicate()` 一份再改 uniform，缓存照旧给别人用。

裁剪盒 = `kit.PLATFORM_CLIP`（x/z ±5.6，与 `street.gd` 的 `B` 一致），
所以切口和底座边缘严丝合缝 —— 车「从画面边缘长出来」，而不是凭空出现在台上。

## 撞击演出

| 时刻 | 事件 |
| --- | --- |
| 车头距人 4.5m | `Engine.time_scale = 0.35`，慢镜头 |
| 命中 | 恢复 1.0；击飞（`player.knock`）、镜头抖 0.11m/0.9s、白闪、低频闷响 |
| +0.10s | 黑场 0.22s |
| +1.05s | 黑场里复位：位置 / 朝向 / 视角 / 速度 / 击飞状态全部还原 |
| +1.05s | 淡入 1.4s + toast |

三处取舍：

1. **车是纯视觉体，不带碰撞。** 真让它推 `CharacterBody3D`，高速下会把人挤进
   底座或卡在车底；撞击感交给「击飞 + 抖 + 白闪 + 收黑」四件套，手感更稳，
   也不用为了这件事去动物理参数（草原场景也在用同一个控制器）。
2. **撞完立刻收黑（0.22s），不留 0.3s 看自己被撞飞。** 车会从镜头上碾过去，
   多留半秒只能看到一整块车皮 —— 像镜头钻进车里。白闪接黑场更干脆。
3. **复位回出生点，不是原地。** 路缘石那儿离店面只有 2m，弹簧臂会直接顶进
   店里，一睁眼就是俯拍天灵盖。回到出生点，镜头朝向和开场完全一致。

## 已知限制

- 只做了南侧车行道一个方向。西侧窄路下马路不会触发（见「触发链」）。
- 命中判定是「车头 x 越过阈值 + 横向 |dz| 在车宽内」的 AABB 近似，不是物理碰撞。
  阈值是单向越过的，所以不会穿帧漏判；击飞是判定瞬间给的一次冲量，
  和车速无关（车再快人也是同样的抛物线）。
- 慢镜头用的是 `Engine.time_scale`，期间雨、涟漪、tween 一起变慢；
  这是想要的效果，但如果将来有 UI 动画在跑，也会一起慢。
